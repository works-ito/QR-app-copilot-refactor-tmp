# QR在庫管理 ver.3

株式会社ワークスのQR在庫管理アプリ ver.3です。

## 現在の段階

- モバイル優先の基本レイアウト
- 入口ウィザード
- 受付方法、作業区分、実施拠点、担当者の選択
- 選択内容の表示
- 戻る／次へ操作

## ファイル構成

- `index.html`：画面の骨格
- `styles.css`：共通デザイン
- `app.js`：状態管理と画面操作

## 次の実装

1. ver.2の業務ルールを整理して入口選択肢へ反映
2. GASの軽量マスタ取得
3. ZXingカメラと連続読取
4. 最新状態判定・二重出庫防止
5. batchWrite・取消
6. イレギュラー受付・写真保存
